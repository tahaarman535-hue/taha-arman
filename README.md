# TAHA ARMAN — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive design and styling
- `script.js` — mobile navigation, active section link, and current year
- `assets/taha.jpg` — your uploaded photo

## Preview on your computer
1. Extract the ZIP file.
2. Open the `taha_arman_portfolio` folder.
3. Double-click `index.html` to open it in your browser.

## Before publishing
Open `index.html` and:
1. Replace `your.email@example.com` with your real email address.
2. Replace the `href="#"` on the GitHub profile link with your GitHub profile URL.
3. Update the skills and project descriptions to match your real experience. The two last project cards and the skill bars are sample placeholders.

## Publish using GitHub website
1. Sign in at https://github.com and click **New repository**.
2. Name it `taha-arman-portfolio` and set it to **Public**.
3. Create the repository.
4. Open the repository, choose **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder (with `taha.jpg` inside it). Do not upload only the ZIP file.
6. Click **Commit changes**.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/(root)`, then click **Save**.
10. Wait a few minutes and refresh the Pages section; GitHub will show your website URL.

If your repository is named `yourusername.github.io`, GitHub Pages can publish it at the root domain. Otherwise, the website URL normally includes `/taha-arman-portfolio/`.
